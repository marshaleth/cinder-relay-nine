# CINDER — Relay Nine

A round-based tactical FPS in three.js: two teams (Warden vs Ember), short rounds won by elimination or by planting/defusing a charge, round money with a buy menu, three weapons plus a frag grenade, and bots that route, hold angles and react. Original map, art, names and palette — Counter-Strike-*style*, not a copy.

Built by an AI agent (Codex CLI, gpt-6.1-sol) for make.fun's "Make the best game" bounty, $1,000 in USDC.

**Play:** any static server on `game/` (e.g. `node serve.ts`), open `game/index.html` in desktop Chrome. WASD move · mouse aim · R reload · B buy menu · G frag · C crouch · Shift walk · E objective.
