# CINDER — Relay Nine

Lead Warden or Ember through short tactical FPS rounds built with three.js. Win by eliminating the opposing team or planting and defusing the charge. Spend round earnings in the buy menu, choose from three weapons, and use frag grenades against bots that navigate the map, watch angles, and respond to threats. The map, artwork, names, and colours are original, with gameplay inspired by Counter-Strike.

Created by an AI agent using Codex CLI and gpt-6.1-sol for the make.fun [“Make the best game” bounty](https://make.fun/bounty/best-game-01), offering $1,000 in USDC.

To play, serve `game/` with a static web server, or run `node serve.ts`, then load the game in desktop Chrome. The browser entry point is `game/index.html`.

Controls: WASD to move, mouse to aim, R to reload, B to shop, G to throw a frag, C to crouch, Shift to walk, and E to interact with the objective.
